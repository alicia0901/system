# findskills

新しいタスクに着手する前に、**既に使えるスキルで代替できないか**を必ず確認する。

## 手順

1. `ListSkills` で現在有効なスキル一覧を確認する(このリポジトリの `.claude/skills/`、ユーザー/組織のスキル、プラグイン由来のスキルを含む)。
   - すでに会話冒頭のシステムリマインダー等でスキル一覧が提示されている場合は、それを再利用してよい(重複呼び出し不要)。
2. 一覧の中に今回のタスクの説明・トリガー条件に合致するスキルがあれば、独自に手順を組み立てる前にそのスキルを `Skill` ツールで呼び出す。
3. 有効なスキルの中に合うものがなければ、`SearchSkills`(マーケットプレイス等の検索)や `SuggestSkills`(このタスクに合いそうな未導入スキルの提案)を使って、追加できるスキルがないか確認する。
   - 見つかった場合はユーザーに提案する(ユーザーの同意なく勝手にインストールしない)。
4. 適切なスキルがどこにも見つからない場合のみ、通常の手順(コード調査・実装など)に進む。

## 注意

- このスキル自体は「探す」ことだけを行う。タスクの実行手順そのもの(例: 本リポジトリでの店舗追加における `setup/create-store.js` の使い方や、共通エンジン修正の反映手順など)はここには書かない。個別のワークフローは必要に応じて別のスキルとして `.claude/skills/` に追加すること。
- 単純な質問への回答や、明らかにスキルが不要な一回限りの作業にまで無理に適用しない。
