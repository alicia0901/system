# Apex Legends コーチング「キツネ」 集客用LP

X(旧Twitter)からの流入を想定した、スマートフォン優先の1ページ完結型ランディングページです。
ビルド不要の静的サイト(HTML / CSS / JavaScript)なので、無料のホスティングでそのまま公開できます。

## ページ構成

| # | セクション | 内容 |
|---|---|---|
| 1 | ファーストビュー | キャッチコピー・キツネのキャラクター・DMボタン・実績の数字 |
| - | 選ばれる理由 | サービスの特徴3点 |
| 2 | コーチ紹介 | プロフィール・Predator到達などの実績 |
| 3 | 受講者のランクアップ実績 / 受講者の声 | ランク推移カード(ランクごとに色分け)・感想 |
| 4 | 料金プラン | 3プラン(おすすめプランを強調) |
| 5 | ご利用の流れ / よくある質問 | 4ステップ / 開閉式のQ&A |
| 6 | 最終CTA | XのDMへの問い合わせボタン |

- DMボタンはヘッダー・ファーストビュー・各料金プラン・最終CTAに配置しています。スマホではスクロールすると画面下に固定表示されます。
- SEO・SNS向けに title / description / OGP画像(`images/ogp.png`)/ canonical / robots.txt / sitemap.xml / よくある質問の構造化データ(FAQPage)を設定しています。

## ファイル構成

```
kitsune-lp/
├─ index.html        ページの骨組み(title・説明文・OGPもここ)
├─ js/content.js     ★ 文章・料金・実績・XのURLなど、更新する内容はすべてここ
├─ js/main.js        content.js の内容をページに表示する処理(通常は触らない)
├─ css/style.css     デザイン(色は先頭の :root で一括変更可能)
├─ images/           画像(fox.svg=キツネ、coach.svg=コーチ画像、ogp.png=Xでのカード画像)
├─ robots.txt
└─ sitemap.xml
```

## 公開前にやること

1. **`js/content.js` の `sampleMode: true` を `false` にする**
   現在入っている数字・実績・受講者の声・料金・プロフィールは仮の内容です。
   `true` の間はページ上部に「サンプル表示中」の帯が出ます。差し替えが終わったら `false` にしてください。
2. **キツネのイラストを差し替える**
   `images/fox.svg` は仮のアイコンです。提供いただいたイラストを `images/` に入れ、
   `index.html` の `images/fox.svg` をそのファイル名に置き換えます(PNGでも可。背景透過がおすすめ)。
3. **Xのアカウントを設定する**(`content.js` の `x`)
   - `handle`: @を除いたユーザー名
   - `userId`: 数字のユーザーID。設定すると、ボタンから**DM作成画面が直接開き**、`dmText` の文章が入った状態になります。
     空欄のままだとXのプロフィールページが開きます。
     数字のIDは「X ユーザーID 調べ方」で検索して出てくる変換サイトなどで、ユーザー名から調べられます。
   - DMを受け取るには、Xの「設定 → プライバシーと安全 → ダイレクトメッセージ」で「すべてのユーザーからのメッセージを許可」をオンにしておいてください(相互フォローでない人からのDMを受けるため)。
4. **公開URLを設定する**
   公開先のURLが決まったら、`index.html` の `https://example.com/`(canonical / og:url / og:image)、
   `robots.txt`、`sitemap.xml` の `https://example.com/` を実際のURLに置き換えます。

## 公開後の更新方法(実績画像・文章・料金)

更新は **`js/content.js` の書き換えと、`images/` への画像アップロードだけ**で完結します。HTMLの知識は不要です。

- **文章・料金を変える**: `content.js` の `' '` で囲まれた文字を書き換える
- **実績・感想・プランを増やす/減らす**: `{ ... },` の1ブロックをコピー&貼り付け/削除する
- **実績画像を載せる**: 画像を `images/` にアップロードし、`results` の `image: ''` を `image: 'images/ファイル名.png'` にする
- **ランクの色分け**: `from` / `to` に `Rookie` `Bronze` `Silver` `Gold` `Platinum` `Diamond` `Master` `Predator` のいずれかを入れると自動で色が付きます

下記の「おすすめの公開方法」で公開しておくと、GitHubのWeb画面でファイルを編集・保存するだけで、1分ほどで本番サイトに反映されます(パソコン・スマホのブラウザから操作できます)。

## おすすめの公開方法(運用費ほぼ0円)

| 項目 | おすすめ | 費用 |
|---|---|---|
| サーバー | **Cloudflare Pages**(GitHubと連携して自動公開) | 無料 |
| ファイル置き場・編集画面 | GitHub(非公開リポジトリでOK) | 無料 |
| ドメイン(任意) | Cloudflare Registrar などで `.com` を取得 | 年1,500〜2,000円前後 |

ドメインを取らない場合も `https://〇〇.pages.dev` という無料のURLで公開できます。

### 手順の概要

1. GitHubにリポジトリを作り、このフォルダの中身をアップロードする
2. Cloudflare のダッシュボード → Workers & Pages → Pages → 「Gitに接続」でそのリポジトリを選ぶ
   (ビルドコマンドは空欄、出力ディレクトリは `/`(このフォルダをリポジトリ直下に置いた場合))
3. 独自ドメインを使う場合は Pages の「カスタムドメイン」から設定する
4. 以降は GitHub 上で `js/content.js` を編集・保存すると自動で反映される

## 確認方法

`index.html` をブラウザで開くだけで表示を確認できます(サーバー不要)。
